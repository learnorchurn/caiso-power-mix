# Attribution and scope

This is a personal portfolio demonstration directed by Richard Couch and built with Codex. It extracts the California power view from Richard's Live Data Lab at https://www.richcouch.com/lab/index.html#power.

The source observations are attributed to CAISO Today's Outlook. Original source URLs, timestamps, and CSV hashes are preserved in `site/data/power.json`. This project is not an official CAISO product and does not imply CAISO endorsement.

No open-source license has been selected for the code or documentation in this repository. Public availability for review does not assign a license to third-party data. Refer to the source provider for its data terms.

This package contains no employer systems, employer datasets, API credentials, or account-specific deployment configuration. The included observations are public CAISO supply readings.
